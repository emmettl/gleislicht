# Shared weather adoption

1 November 2026. Pins `@motionstudies` packages to alpha.46 and removes duplicated weather infrastructure. The source cloud artifacts, dates and scene treatments remain unchanged.

Decoded gzip/identity bytes use the bounded shared verifier; percentage/validity pixels use core; the two-frame GPU lifecycle uses three. Manifest validation, the existing clock brackets, cloud appearance and illustrative terrain shadows remain local.

Validation and extraction boundaries: [shared weather infrastructure](https://github.com/emmettl/motionstudies/blob/main/docs/WEATHER-FIELDS.md). npm publication and this source adoption are separate from verification of any served deployment.

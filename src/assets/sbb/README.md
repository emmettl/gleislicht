# SBB transport icons

Official, unmodified SVGs from [sbb-design-systems/sbb-icons](https://github.com/sbb-design-systems/sbb-icons),
revision `8ccbce0ab5402043b6d0faae5ef26afbc97b4095` (retrieved 2026-09-08).
Source files: `icons/<filename>.svg`. See the accompanying Apache-2.0 `LICENSE`.

The interface uses the SVGs as CSS masks to inherit its service colours, preserving
the original artwork and proportions. Rail service classes and metro share the
train symbol; cogwheel railways use SBB's `rack-railaway-profile-small` artwork.
Labels distinguish service classes and supply accessible names; icons are decorative.
